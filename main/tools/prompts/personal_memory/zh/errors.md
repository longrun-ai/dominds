# personal_memory：失败处置

记忆工具返回结构化失败结果及说明正文，没有固定的 MEMORY\_\* 错误码目录。根据实际结果判断如何恢复。

## 记忆已存在或不存在

新增路径已存在时，应先读已有内容；确实要更新时使用对应的 replace 工具，不要另造路径绕过检查。替换与删除要求路径存在。若记忆不存在，先确认操作意图，再决定是否新增。

## 输入无效

提供非空相对路径，路径不得包含 `..`；新增和替换的内容不能为空。个人路径不要重复成员 id，工具已自动提供私有命名空间。Dominds 没有只允许字母等少数字符的规则，也没有固定的 255 字符路径上限或 1 MB 内容上限；底层文件系统仍可能拒绝某些名称或路径。

## 存储失败

根据实际文件系统错误检查相关路径、存储空间和权限，修正原因再重试。写入结果不确定时，先检查当前文件，再决定是否重复操作。记忆保持精炼是为了控制后续上下文和信息过期成本，不是为了满足不存在的容量限制。

## 归属与删除

个人记忆按当前成员隔离；清空会移除该成员全部个人记忆，工具不提供撤销。
